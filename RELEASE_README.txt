WildTrace v0.16.0 Beta 2
====================

Read-only live radar and population scanner for theHunter: Call of the Wild.

INSTALL
-------
1. Extract the entire ZIP to a normal folder.
2. Start theHunter: Call of the Wild and load into a reserve.
3. Run WildTrace.exe.
4. Select your reserve and press Attach.
5. On first use, open Control Center and use "Build maps from game" if needed.

IMPORTANT
---------
- Keep the offsets and data folders beside WildTrace.exe.
- WildTrace is read-only. It does not write to game memory or modify save files.
- Patch-specific memory offsets can break after a COTW update. WildTrace fails closed when the executable fingerprint/profile no longer matches.
- Layton Lake currently has the verified live world-to-map calibration. Other reserve maps may use fallback behavior until calibrated.
- Native animal difficulty is still experimental. Weight-derived difficulty is shown with ~ where applicable.

REQUIREMENTS
------------
- Windows 10/11 x64
- Legitimate PC installation of theHunter: Call of the Wild
- No separate .NET installation is required by the self-contained release.

PRIVACY / NETWORK
-----------------
WildTrace does not require account registration and does not need internet access for its core functionality.
